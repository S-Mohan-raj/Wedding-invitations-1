# The Wedding Edit — 18 Wedding Website Designs

## Open the gallery
Open `index.html` in a modern browser. The gallery contains 18 separate wedding invitation website previews. Select **Explore design** on any card to open that complete invitation inside the gallery viewer. Use **Back to gallery** to return; browser back and Escape are also supported.

## Notes
- Keep the `designs/` folder beside `index.html`; previews load standalone HTML files from this folder.
- Google Fonts and sample Unsplash photography require an internet connection.
- Names, family details, event times, venue, date and RSVP deadline are sample content. Update details in the standalone site(s) you plan to use.
- RSVP opens WhatsApp with a pre-filled message. Set the WhatsApp number in each individual page's `data-whatsapp-number` attribute before using it for real guest responses.
- The site is built with HTML, CSS and vanilla JavaScript. No build step or framework is needed.

For hosting, upload the entire folder while preserving the `designs/` directory structure.
